# Landlord's Super_RUS
Русификатор для игры Landlord's Super создан и переведен при помощи Claude

РУСИФИКАТОР LANDLORD'S SUPER  (версия игры 1.0.09)
=====================================================

Полный перевод игры на русский язык: меню, интерфейс, предметы, подсказки, каталоги, письма, диалоги. 

Требования
  Windows, Steam-версия игры. Русификатор проверялся на версии 1.0.09.

Установка
  1. Закройте игру.
  2. В Steam: ПКМ по игре -> Управление -> Просмотреть локальные файлы.
  3. Распакуйте содержимое архива в открывшуюся папку (рядом с LandlordsSuper.exe), соглашаясь на замену файлов.
  4. Запустите игру.

Удаление
  Удалите из папки игры: папку BepInEx, файлы winhttp.dll, doorstop_config.ini, .doorstop_version (если есть) и cyrillicfont.

Использованные компоненты
  BepInEx 5.4.23.5 (LGPL-2.1), XUnity.AutoTranslator 5.6.2 (MIT), шрифт Exo 2 (SIL Open Font License 1.1).
